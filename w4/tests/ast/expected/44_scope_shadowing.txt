AST 44 — scope_shadowing
Source: tests/ast/cases/44_scope_shadowing.c

int x;
int main() {
    int x;
    x = 1;
    { int x; x = 2; }
    return x;
}

MANUAL VALIDATION
- There are THREE distinct declarations named x: levels 0, 1 and 2.
- Assignment x=1 uses X_OUTER (level 1).
- Assignment x=2 uses X_INNER (level 2).
- return x uses X_OUTER again after leaving the inner block.
- X_GLOBAL is shadowed inside main and must not be referenced by these statements.
- Level numbers describe this project's enterScope()/leaveScope() behavior.
- Pointer addresses printed by print.c are runtime-dependent.
